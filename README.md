# Ramier Business Solutions — Portfolio Website

Responsive static website based on the supplied Canva PDF, expanded with services informed by professional experience.

## Publish to GitHub Pages
1. Create a **public** GitHub repository named `ramai-portfolio`.
2. Upload the contents of this folder (not the enclosing folder) to the repository root.
3. In Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)`, then Save.
4. Test the GitHub Pages URL first.
5. In Pages, add custom domain `ramai-solutions.com`.
6. At GoDaddy, replace the old website A record with GitHub Pages A records for `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; change `www` CNAME to `<your-github-username>.github.io` (replace placeholder). Preserve NS, SOA, `_domainconnect`, and any email DNS records.
7. Allow DNS propagation, verify DNS in GitHub Pages, then enable **Enforce HTTPS** when available.

## Before launch
- Verify employment dates and whether 'Present' remains accurate.
- Confirm package pricing currency, hours and phone numbers.
- Replace PDF-derived portfolio images with original high-resolution photos if available.
- Verify any work samples contain no confidential client or employee information.
- Confirm booking availability: current buttons use email enquiries rather than an invented booking link.
- The original PDF lists 100% job success and 99% client satisfaction; these were intentionally omitted until verified.
